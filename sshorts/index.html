Quick start

  1. Enter the short title, subject and usual slide duration in Lesson setup.
  2. Choose a lesson template and select Create from template, or add slides individually.
  3. Select each slide in Slides and editing, then edit its heading, content, colours, duration and transition.
  4. Add narration, an optional web camera overlay and optional background music.
  5. Use Preview, correct anything necessary, then export the 1080 × 1920 WebM video.
Good short: Teach one idea, open with a hook, keep text concise and finish with one clear action.

Creating and editing slides

Use the eight slide buttons for a hook, explanation, spoken text, code, question, answer, image or call to action (CTA). The selected slide appears in the editor.

  • Move: Use ↑ and ↓ to change the slide order.
  • Duplicate: Select ⧉ to make a copy, then edit it.
  • Delete: Select × and confirm.
  • Code: Choose the language. Long code moves upward without shrinking its code font.
  • Image: Use Contain to show the complete picture or Cover to fill the available area.
  • Duration: Give viewers enough time to read. Narration can automatically extend a slide.

Open Brand settings to set the teacher, channel, website, colours and logo. A transparent PNG or WebP logo usually looks best.

Narration, speech and music

  1. Select a slide and type the words to be spoken in Narration and highlighted words.
  2. Keep Remove background noise selected for speech. It reduces echo, steady noise, rumble and hiss.
  3. Select Start recording, speak clearly, then select Stop recording.
  4. Use Play to check the result. Re-record or remove it if needed.

You may upload an existing audio file instead. Highlighted captions follow the narration text. The Spoken Text slide's browser voice is for rehearsal; record or upload narration for exported sound.

Background music loops through the video. Keep its volume low enough that speech remains clear.

Using the web camera

  1. Open Web camera and select Start camera.
  2. Allow camera permission in the browser.
  3. Choose its corner, size, frame shape and mirror setting.
  4. Leave the camera running while previewing, recording narration and exporting.

The camera is composited into the preview and final video. Select Stop camera when finished.

Preview, cover and video export

Use ◀ and ▶ to inspect individual slides. Select Preview to play the complete short, and drag the progress control to inspect a transition.

  • Download cover saves the currently selected slide as a PNG.
  • Export 1080 × 1920 video creates a vertical WebM with narration, music and the live camera overlay.

Keep this page visible until rendering finishes. The status message reports progress slide by slide.

Saving and reopening projects

The browser keeps a local working copy automatically. Use Save project to download a portable JSON backup. Use Open project later to continue editing that file. New clears the current project after confirmation.

Troubleshooting

Camera or microphone does not start
Run the app through HTTPS or localhost, allow browser permission and close other apps using the device.
No camera in the exported video
Start the camera before export, confirm that the live camera appears in Preview and keep it running until rendering finishes.
Narration is noisy or too quiet
Keep noise removal enabled, move closer to the microphone and record in a quieter room. Disable filtering only for music or non-speech recordings.
Pictures or logo do not appear
Choose a common browser format such as PNG, JPG or WebP, then wait for the preview to update before exporting.
Export is slow
The app renders the video in real time. Keep the tab active and avoid starting another export simultaneously.
