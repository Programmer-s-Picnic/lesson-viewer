# Boxes, Banners and Lines Board

A beginner-friendly teaching board for simple diagrams.

## Main options

1. **Create Boxes**
   - Type values such as `2,3,4,55,6`.
   - Click **Create Boxes**.
   - Each value becomes one movable numbered box.

2. **Create Banners**
   - Type headings such as `Start, Compare, Swap, Finish`.
   - Click **Create Banners**.
   - Each heading becomes a wide movable banner.


3. **Change Text**
   - Click **Move**.
   - Select a box or banner.
   - Type the new text in **Change Text**.
   - Click **Update Selected Text**.
   - You can also double-click a box or banner to edit it quickly.

4. **Movement Lines**
   - Click **Movement Lines: Off** to turn it on.
   - Move boxes or banners.
   - The board will draw blue arrow lines from the old position to the new position.
   - Click it again to turn movement lines off.

5. **Draw Line**
   - Click **Draw Line**.
   - Drag on the board to draw a straight line.
   - Use this for teaching steps, sorting movements, comparisons, and arrows between ideas.

6. **Eraser**
   - Click **Eraser**.
   - Click or drag over boxes, banners, or lines to remove them.
   - Use **Ctrl+Z** to undo an erase.


## Editing text directly inside boxes and banners

- Double-click any box or banner.
- A text box opens directly inside that item.
- Type the new text.
- Press **Enter** or click outside to save.
- Press **Esc** to cancel.

## Moving items

- Click **Move**.
- Drag an item to move it.
- Drag empty space to select many items.
- Drag any selected item to move all selected items together.

## Utilities

- **New Board** clears the board.
- **Save PNG** downloads the board as an image.
- **Fullscreen** expands the board for teaching or presentation.
