Boxes, Banners and Lines Board Create boxes, banners, draw lines, and erase mistakes.
1. Create Boxes

Type values like 2,3,4,55,6. Each value becomes one movable box.

2. Create Banners

Type headings like Start, Compare, Swap, Finish. Each heading becomes one wide banner.

3. Change Text

Double-click a box or banner and edit the text directly inside it. This input is also available for selected items.

Select a box or banner to change its text.
How to use: Use Create Boxes or Create Banners. Double-click a box or banner to edit its text directly inside it. Turn Movement Lines on if you want arrows after moving boxes. Ready
Double-click any box or banner to type directly inside it. Press Enter or click outside to save. Press Esc to cancel.
