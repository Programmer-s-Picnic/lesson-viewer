Tabla + Sitar + Microphone Music Composer

Open index.html in a modern browser. Use the Toggle Guide button inside the page for full instructions.

Basic steps:
1. Click Unlock Audio.
2. Edit Tabla and Sitar command boxes.
3. Click Play Mix.
4. Enable Microphone if needed.
5. Start Recording, play the mix, then Stop Recording.
6. Download the recording.

MP3 recording is attempted first. If the browser does not support MP3 MediaRecorder, the page saves WebM automatically. Microphone access requires HTTPS or localhost in most browsers.
