1. What Is Claude?

Claude is an artificial intelligence assistant created by Anthropic.

We can communicate with Claude using ordinary language.

For example, we can ask:

Explain Python to a complete beginner.

Or:

Give me five simple examples of what Python can be used for.

Or:

Write the simplest possible Python program.
Important idea: You do not need to know programming before you can begin asking Claude programming questions.

3. Your First Claude Prompt

Open Claude.

Type:

Hello Claude. I am learning programming for the first time. What is Python? Explain it using very simple language.

Read Claude's answer.

Then continue the same conversation:

What can I make using Python? Give me five very simple examples.

What Is a Prompt?

A prompt is simply an instruction, question or message that we give to an AI.

Teacher: Do we need a special programming language for talking to Claude?

Student: No.

Teacher: Correct. We can use normal language. The instruction we give Claude is called a prompt.

4. Better Prompts

Compare:

Explain Python.

with:

I have never programmed before. Explain Python as if this is my first programming lesson. Use simple English and one everyday example.

The second prompt gives Claude information about the learner.

This information is called context.

Lesson: Better context usually helps an AI produce a more useful answer.

5. What Is Programming?

Ask Claude:

I am a complete beginner. What is a computer program? Explain it in no more than five sentences.

The basic idea is simple.

A computer program is a set of instructions given to a computer.

For example: 

Display Hello

In Python, we can express this instruction using: 

print("Hello")

8. Understand print()

Return to Claude and ask:

Explain this Python program to a complete beginner: print("Hello, World!") Explain every part in simple language.

The most important command is: 

print()

It tells Python to display something.

The text: 

"Hello, World!"

is placed inside quotation marks because Python must understand that it is text.

11. Make an Error Deliberately

Enter: 

print("Hello, World!)

One quotation mark is missing.

Run the program.

Python should display an error.

Errors are normal. Every programmer makes errors. Learning to understand them is one of the most important programming skills.

Ask Claude for Help

I am a Python beginner. This program gives an error: print("Hello, World!) Do not simply fix it. First explain what is wrong. Then give me a hint. Finally show the corrected program.

The corrected version is: 

print("Hello, World!")

Use Claude as a Tutor

Avoid simply asking:

Fix my code.

A better learning prompt is:

I am learning Python. Here is my code: [PASTE CODE] Here is my problem: [DESCRIBE PROBLEM] First explain what is wrong. Then give me a hint. Do not give me the complete solution unless I ask for it.
Use AI as a teacher and tutor, not merely as an answer machine.

12. Text and Numbers Are Different

Run: 

print(100)

Then: 

print(20 + 30)

Expected output: 

50

Now run: 

print("20 + 30")

Expected output: 

20 + 30

Why?

Explain the difference between: print(20 + 30) and print("20 + 30") Explain it to someone in their first Python lesson.
