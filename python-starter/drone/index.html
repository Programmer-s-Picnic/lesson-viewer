Lesson

How this drone page works

1. A command is one instruction

TAKEOFF starts the drone. MOVE 160 moves it 160 pixels. One line means one step in the mission.

2. Sequence matters

The computer runs the script from top to bottom. MOVE before TAKEOFF is ignored because the drone is still on the ground.

3. Coordinates locate points

The arena uses x from left to right and y from top to bottom. Use GOTO x y to move to a waypoint.

4. Heading controls direction

TURN 90 changes the direction. After turning, MOVE follows the new heading.

5. Safety checks stop bad moves

The simulator checks boundaries, obstacles and battery. When something unsafe happens, the mission stops with a clear message.

6. Animation loop updates the world

JavaScript uses requestAnimationFrame to update the drone and redraw the arena smoothly.

Help Center — Online Drone Simulator

Commands, examples, coordinates, and common mistakes.

How it works: Each line is executed top-to-bottom. Movement works only after TAKEOFF. Use TURN then MOVE to draw shapes. Use GOTO x y for waypoints.
Command Meaning Example
TAKEOFFStart flying. Enables movement commands.TAKEOFF
LANDLand the drone. End mission safely.LAND
MOVE <d>Move along current heading. Positive means forward, negative means backward.MOVE 160
TURN <deg>Rotate. Positive turns left, negative turns right.TURN 90
GOTO x yMove to a coordinate waypoint.GOTO 800 120
WAIT sPause the mission while hovering.WAIT 0.5
HOMEReturn to the home point.HOME
SETSPEED vSet movement speed for MOVE and GOTO.SETSPEED 140
Common mistakes:
  • MOVE before TAKEOFF → ignored with a clear status message.
  • Obstacle collision → mission stops. Use GOTO around the obstacle.
  • Boundary reached → mission stops. Stay inside the arena.
  • Wrong argument → the parser reports the exact line number.

SETSPEED 140
MOVE 160
