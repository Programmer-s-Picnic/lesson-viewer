Boxes and Banners Board Only two creation options: boxes and banners.
1. Create Boxes

Type values like 2,3,4,55,6. Each value becomes one movable box.

2. Create Banners

Type headings like Start, Compare, Swap, Finish. Each heading becomes one wide banner.

How to use: Drag empty space to select many items. Drag any selected item to move all selected items. Press Delete to remove selected items. Ready
Only boxes and banners can be created. Existing items can be selected, moved, deleted, and saved as PNG.
